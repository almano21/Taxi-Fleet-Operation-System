# Taxi-Fleet-Operation-System
C-based taxi fleet management system for managing taxi orders, driver assignment, online payments, and daily operational reports.

- Giorgi Jajanidze

- Timur Kabanchuk

## Project Description

The Taxi Fleet Management System is a C-based application designed to manage taxi orders, drivers, vehicles, payments, and operational reports.

Clients place taxi orders through a web application by providing the pickup time, pickup address, contact phone number, and destination. The system checks driver availability and assigns the nearest available driver.

If no free drivers are available, the system checks drivers who are currently en route and assigns a suitable driver within the maximum allowed distance.

The system also supports online payments using registered client profiles with linked bank cards and generates daily reports containing the total number of trips, revenue, and statistics for individual drivers.
