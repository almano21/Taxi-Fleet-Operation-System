# Taxi-Fleet-Operation-System

C-based taxi fleet simulation for student bookings, driver assignment, simulated payments, and fleet reporting.

## Project

TUDENGITAKSO is a console application for TalTech students travelling between six fixed locations. It supports student registration, fictional card linking, taxi booking, driver assignment, simulated payment, trip cancellation and completion, and administrator fleet reports.

## Build and Run

Requirements: GCC and Make.

```sh
make clean
make
./tudengitakso
```

On Windows, run these commands in a terminal with GCC and Make installed. The text files `drivers.csv` and `trip_log.csv` are created in the working directory.

## Module Structure

- `main.c`: program startup, data loading/saving, and memory cleanup.
- `menu.c`: client and administrator menus.
- `trip.c`: booking validation, locations, distance lookup, and fare calculation.
- `driver.c`: driver selection and dynamic driver-array allocation/resizing.
- `admin.c`: administrator authentication and fleet-change permissions.
- `storage.c`: CSV loading and saving.
- `.h` files: shared data definitions and function declarations.

The files group related responsibilities so that changes to one area are easier to locate. The Makefile compiles each module and links the program consistently.
